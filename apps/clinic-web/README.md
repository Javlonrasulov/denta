# DENTA.UZ Clinic CRM (Web)

Next.js + TypeScript desktop/tablet Clinic CRM.

```bash
cd apps/clinic-web
npm run dev
```

Open: http://localhost:3000

## Modules

- Overview, Appointments, Patients, Doctors
- Rooms, Services, Finance, Inventory, Reports, Settings

## Not Expo

This is a separate web product. Do **not** use `expo start --web` as Clinic CRM.
